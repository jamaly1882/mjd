## إعادة البناء

```bash
python3 -m venv .venv
.venv/bin/pip install pymupdf pillow fonttools brotli
.venv/bin/python build_cv.py
```

السكربت ينزّل الخطوط تلقائيًا من حزمة `@fontsource/cairo` على سجل npm إن لم
تكن موجودة، ويستخرج الأيقونات الدائرية من ملف السيرة الأصلي، ثم يرسم الخلفية
ويضع النصوص العربية عبر محرك HTML في PyMuPDF (تشكيل HarfBuzz).
