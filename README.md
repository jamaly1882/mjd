# السيرة الذاتية المحدّثة — مجد الشاهري

تم إنتاج سيرة ذاتية من **صفحة واحدة** بنفس هوية تصميم ملف
`سيف البتول-السيرة الذاتية-1.pdf`، مع:

- تغيير الاسم إلى **مجد الشاهري** وإضافة سطر تعريفي بمهنته.
- استبدال الصورة الشخصية بالصورة المرفقة `IMG-20261026-WA0001.jpg`.
- دمج كل معلومات ملف `انشا ملف مجد.pdf` في الصفحة الأولى:
  - الخبرات: معيد جامعي 2019، مدير صندوق النشء والشباب للتعليم المهني والفني
    2020 في إحدى المحافظات، مهندس حفر لـ 21 بئرًا في اليمن، مراقب جيولوجي
    للمكامن الإنتاجية، مراقب تشغيل وإنتاج وصيانة لمشاريع خدمية وإنتاجية،
    موظف فني في الإدارة الفنية بشركة المياه والصرف الصحي،
    ورقم الهاتف `00966530663905`.
  - التعليم: بكالوريوس هندسة نفط وغاز من جامعة تونتك الماليزية 2017/2018
    (الأول على الدفعة، تقدير ممتاز، معدل 95%)، وماجستير تمهيدي في إدارة
    الأعمال من جامعة سبأ 2026.
  - صياغة «نبذة مختصرة» ووصف مهني موسّع للخبرات استجابةً لطلب الشرح في الملف.
- الإبقاء على أقسام ومحتوى السيرة الأصلية (المعلومات الشخصية، خبرات المبيعات،
  الدورات، المهارات، اللغات) مُدمجة بصيغة مختصرة.

> **ملاحظة:** بيانات مثل البريد الإلكتروني وتاريخ الميلاد والحالة الاجتماعية
> مأخوذة من السيرة الأصلية لأنها غير موجودة في ملف مجد؛ يُنصح بمراجعتها قبل
> إرسال السيرة. رقم هاتف ملف مجد أُضيف بجانب رقم الجوال الأصلي.

## الملفات

| الملف | الوصف |
| --- | --- |
| `مجد الشاهري-السيرة الذاتية.pdf` | السيرة النهائية (صفحة واحدة، نص قابل للتحديد) |
| `مجد الشاهري-السيرة الذاتية.png` | معاينة بدقة عالية |
| `مجد الشاهري-السيرة الذاتية.txt` | نسخة نصية نظيفة للنسخ والتعديل |
| `build_cv.py` | سكربت إعادة بناء السيرة |
| `assets/fonts/` | خطوط Cairo المستخدمة في الكتابة العربية |

## إعادة البناء

```bash
python3 -m venv .venv
.venv/bin/pip install pymupdf pillow fonttools brotli
.venv/bin/python build_cv.py
```

السكربت ينزّل الخطوط تلقائيًا من حزمة `@fontsource/cairo` على سجل npm إن لم
تكن موجودة، ويستخرج الأيقونات الدائرية وإطار الصورة من ملف السيرة الأصلي،
ثم يرسم الخلفية ويضع النصوص العربية عبر محرك HTML في PyMuPDF (تشكيل HarfBuzz).
